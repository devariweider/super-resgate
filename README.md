# Super Resgate 2D

Projeto HTML5/CSS/JavaScript para computador, celular e controle USB.

## Publicação

A versão jogável completa está no pacote `GPATROLPAW-Tela-Inteira-Responsiva.zip`. Para publicar, extraia o ZIP e envie **todos** os arquivos e a pasta `assets/` à raiz da branch `main` pelo menu **Add file → Upload files** do GitHub. Preserve os nomes e subpastas.

Depois, em **Settings → Pages**, escolha **Deploy from a branch**, `main`, `/ (root)` e salve.

**Nota:** até que `game.js`, `style.css` e `assets/` sejam adicionados, o `index.html` não consegue executar o jogo.
